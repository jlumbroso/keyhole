# Keyhole manual

Start with [Keeping secrets out of the conversation](keeping-secrets-out-of-the-conversation.md):
choose your coding assistant, configure its file protections, and check them
with a harmless value before introducing a real credential.

These are the manual's editable sources. The first chapter is documentation
checked against vendor sources, with its verification limits recorded in the
chapter. It is not yet a deployed manual site.

To suggest a correction, open a pull request changing the relevant Markdown
file, or [open a documentation issue](https://github.com/jlumbroso/keyhole/issues/new).
Include the assistant's name and version, your operating system, and the step
that differed. Never attach a credential, environment dump, or secret-bearing
configuration file.
